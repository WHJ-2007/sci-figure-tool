# 科研图结构化质量协议

本项目将 [icebird1998/scientific-illustrator](https://github.com/icebird1998/scientific-illustrator) 的平台无关设计思想迁移到原生 SVG 画布：Designer → Drawer → Reviewer → Corrector。上游项目采用 MIT License；本项目没有复制其 PowerPoint、WPS、COM、OOXML 或 MCP 后端实现，而是针对现有可编辑画布重新实现确定性审查与纠错。

## 为什么这样迁移

用户配置的模型可能没有视觉能力，不能通过截图可靠判断构图。因此，画布把科研节点、容器、连线和装饰写成机器可读角色，审查器直接使用坐标、包围盒、文字估算尺寸、端点引用和折线路径计算质量。

## 交付门禁

每次科研图生成完成后，系统自动检查：

- 拓扑和端点引用；
- 原生对象可编辑性；
- 越界、节点遮挡和文字容纳；
- 节点净距和基本排版一致性；
- 连线穿过无关节点与无关连线交叉；
- 字号和语义调色板复杂度。

报告包含 0–1 分项分数，以及每项问题的对象 ID、区域、严重度、数值证据、修复动作、验收条件和置信度。硬错误触发最小对象级纠错并重新审查；图形不会被压成不可编辑位图。

结构门禁不能验证科研事实是否正确。论文中的实验结论、数据、方法关系和领域语义仍必须以用户材料或可靠来源为准。

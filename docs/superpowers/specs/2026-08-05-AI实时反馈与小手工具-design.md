# AI 实时绘制反馈与小手平移工具 — 设计文档

日期：2026-08-05
状态：已批准

## 1. 概述

在已收官的 20 任务科研制图工具基础上新增两个独立小功能：

1. **AI 生成实时绘制反馈**：AI 生成/修改画布时，每个元素操作（创建/修改/删除）立即反映到画布上，逐步看到图形成形，而不是等全部生成完才一次性出现。
2. **小手平移工具**：工具栏最左侧新增"小手"工具（内联 SVG 手掌图标，非 emoji），选中后在画布上拖拽可平移视口。当前视口仅有滚轮缩放（0.25x–4x），无平移机制。

## 2. 现状（改动基础）

- 事件协议（`src/lib/ai/agent.ts`）：`AgentEvent = progress（每轮工具调用后的文本活动）| complete（最终画布+总结）| error`
- 服务端 `runAgent`：`onStepFinish` 时把 `draft.flushActivity()` 文本作为 progress 推送；画布仅在 complete 事件一次性下发 `draft.serialize()`
- 客户端 `ChatPanel.tsx`：收到 complete 才 `setDoc(finalDoc)` 应用画布；生成中 `isGenerating` 锁用户交互
- `store.setDoc` 会 `pushHistory`（压入撤销栈）
- 视口：`view = { scale, ox, oy }` + `setView`；仅 onWheel 缩放，无拖拽平移
- 工具栏（`Toolbar.tsx`）：顶部横排按钮，图标均为 Unicode 符号（↖ ▢ ○ △ ◇ ⬡ → ↯ T ↩ ↪ ⚙），激活态 `bg-blue-100 text-blue-700 ring-1 ring-blue-400`
- 交互层：`usePointerInteraction(worldX, worldY)` 统一处理绘制/选择；`onDoubleClick` 双击文字编辑

## 3. 功能 1：AI 生成实时绘制反馈

### 3.1 事件协议

`AgentEvent` 新增分支：

```ts
| { type: "snapshot"; canvas: CanvasDocument }
```

生成中的事件序列：`progress → snapshot → progress → snapshot → … → complete`。snapshot 与 progress 均可能在 complete 前出现 0~N 次。

### 3.2 服务端（draft.ts / agent.ts）

- `DraftCanvas` 增加构造参数回调 `onChange?: () => void`；`createElement`、`updateElement`、`deleteElement`、`clear` **成功修改后**调用（未修改成功如元素不存在时**不**调用）
- `runAgent` 构造 draft 时挂回调：`onChange → onEvent({ type: "snapshot", canvas: draft.serialize() })`
- `complete` 事件保持不变（仍携带最终画布，供客户端整体入栈）

### 3.3 客户端（store.ts / ChatPanel.tsx）

- store 新增 `applyAISnapshot(doc: CanvasDocument)`：`structuredClone` 替换 doc、清空 selection 与 editingText，**不 pushHistory**（`setDoc` 保持入栈语义不变）
- `ChatPanel` 流处理：`snapshot` → `applyAISnapshot`；`complete` → 现有 `setDoc`（入栈一次）
- 生成中画布锁定用户交互不变（`isGenerating` 只锁用户，AI 应用不受影响）
- 面板日志保持现状（progress 滚动显示）；snapshot 事件不进面板

### 3.4 撤销语义

- 中间 snapshot 不入栈 → 生成中/生成失败停在中途状态时，Ctrl+Z 可一步回到生成前
- complete 时 setDoc 入栈一次 → 生成完成后 Ctrl+Z 一步退回整个生成前
- 重做（redo）语义不受影响

## 4. 功能 2：小手平移工具

### 4.1 类型与工具栏

- `ToolType` 增加 `"hand"`
- `Toolbar.tsx` TOOLS 数组**最左端**插入 `{ title: "小手", tool: "hand" }`，图标为**内联 SVG 手掌**（16px 描边风格，与按钮尺寸一致；禁用 emoji/Unicode 手掌字符）
- 激活态与其他工具一致（`bg-blue-100 text-blue-700 ring-1 ring-blue-400`）

### 4.2 画布交互（Canvas.tsx / usePointerInteraction.ts）

- `tool === "hand"` 时：
  - `onPointerDown`：记录起始 clientX/Y 与当前 `view.ox/oy`，进入平移拖拽状态（不经过选择/绘制逻辑，不生成 DrawPreview）
  - `onPointerMove`：`setView({ ...view, ox: ox0 + dx, oy: oy0 + dy })`（画布跟随鼠标：内容向拖拽方向移动）
  - `onPointerUp`：结束
- 画布光标：hand 模式下 `cursor: grab`，拖拽中 `cursor: grabbing`
- hand 模式下禁用：元素点击选中/移动/缩放、框选、绘制预览、双击文字编辑（`onDoubleClick` 增加 `tool === "hand"` 短路）
- 滚轮缩放、快捷键、属性面板、导出等不受影响；视口平移不进撤销历史（与现有 setView 一致）
- 生成中（isGenerating）画布锁定时 hand 拖拽同样禁用（与现有交互一致）

## 5. 测试

### 5.1 agent.test.ts

- 断言事件序列：progress/snapshot 交错、complete 收尾
- 断言 snapshot 的 canvas 与最终 complete canvas 的 elements 一致（相同序列化）
- 断言错误操作（如 update 不存在的元素）不触发 snapshot

### 5.2 chat.test.tsx

- 模拟流响应：先 snapshot（含部分元素）后 complete（含全部元素）→ 断言 store 元素在 complete 前已出现、complete 后为最终状态
- 断言 complete 后撤销一次回到生成前（snapshot 未入栈、setDoc 入栈一次）

### 5.3 store 单测（store.test.ts 或新增）

- `applyAISnapshot` 替换 doc、清空 selection、不入历史栈（undo 不受影响）

### 5.4 小手工具（Canvas-interaction.test.tsx 或新增）

- hand 工具下拖拽 → `view.ox/oy` 按拖拽量变化
- hand 拖拽不选中/不移动元素（doc.elements 不变）
- 非 hand 工具下拖拽行为不变（回归）
- 光标 class：hand 模式 grab、拖拽中 grabbing

## 7. 范围外（不做）

- 按住空格临时切换小手（用户已确认仅工具栏工具）
- 平移惯性/动量
- 视口平移动画
- 面板内实时小图预览

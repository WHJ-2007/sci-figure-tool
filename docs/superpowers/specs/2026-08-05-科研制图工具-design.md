# 科研制图工具 — 设计文档

日期：2026-08-05
状态：已批准

## 1. 项目概述

一个本地运行的科研制图工具（Windows），用于制作 **AI 算法架构图、大数据/医学领域示意图、数学建模图形**。核心能力：

- 在画布上绘制形状、文字、箭头并自由编辑
- 通过内置 AI 智能体（agent + skill 形式）对话：一键生成整图，或针对现有图修改
- 导出 SVG / PNG（矢量图可插入 LaTeX 论文）

技术栈：Next.js 15 (App Router) + React 19 + TypeScript + Tailwind 4 + Vercel AI SDK（DeepSeek）+ Zustand + Vitest/Testing Library。带 PowerShell 启动器。

## 2. 技术决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 画布技术 | **SVG + React 渲染** | 每个元素是一个 SVG DOM 节点，AI 工具调用与元素属性一一对应；原生 SVG 导出；元素量（几十~几百）性能足够 |
| AI 状态管理 | **服务端草稿 + SSE 流式进度** | 用户能实时看到 AI 逐步构建；中断可丢弃草稿不影响当前画布 |
| API Key 存储 | localStorage + 服务端路由代理转发 | 本地个人工具，设置页输入，密钥不出本地 |
| 画布状态管理 | Zustand | 轻量、易测 |
| AI 适配 | `@ai-sdk/openai-compatible`，baseURL `https://api.deepseek.com` | DeepSeek 兼容 OpenAI 协议 |

## 3. 画布数据模型

画布固定 1600×1000，支持滚轮缩放、拖拽平移、网格显示。

### 元素类型

- **形状**：矩形（`rx` 区分圆角矩形）、椭圆/圆形、三角形、菱形、六边形
- **箭头**：直线箭头、折线箭头（流程图用）；从形状边缘拖出，端点自动吸附形状边缘
- **文字**：独立放置，或附加到形状上（文字元素带可选 `parentId`，跟随父元素移动与旋转）

### 统一属性

```
id, type, x, y, width, height, rotation,
fill, stroke, strokeWidth, opacity, zIndex
```

文字专属：`text, fontSize, fontFamily, bold, italic, align`

### 文档结构

```
CanvasDocument = {
  width: 1600, height: 1000,
  elements: CanvasElement[]   // 按 zIndex 排序渲染
}
```

## 4. 编辑器功能

- 选择、框选、拖动、8 向缩放手柄、旋转、删除、复制粘贴
- 层级上移/下移、对齐（左/右/上/下/水平居中/垂直居中）、均匀分布
- 撤销/重做（历史栈）
- 双击文字直接编辑
- 属性面板（选中元素时显示）：填充色、边框色、线宽、透明度、旋转、字体、字号、粗体/斜体、对齐方式
- 工具栏：选择、矩形、圆角矩形、椭圆/圆、三角形、菱形、六边形、箭头、折线、文字
- 导出：SVG 直接序列化下载；PNG 经 SVG→Image→Canvas 转位图下载

### 界面布局（已确认：方案 A）

- 顶部工具栏
- 中央画布（主体）
- 右侧区域上下堆叠两块：
  - **属性面板**（上）：选中元素时显示其属性编辑项
  - **聊天抽屉**（下）：对话历史 + 输入框 + "一键生成"按钮，可折叠；AI 生成时自动展开显示进度
- 设置入口：工具栏齿轮图标 → `/settings` 页

## 5. AI 智能体（agent + skill）

服务端 `/api/chat` 运行 agent 循环，工具集即模型可调用的"技能"：

| 工具 | 参数 | 作用 |
|---|---|---|
| `createElement` | type, x, y, width, height, props | 创建形状/文字/箭头 |
| `updateElement` | id, patch | 修改任意属性（位置、颜色、文字等） |
| `deleteElement` | id | 删除元素 |
| `listElements` | — | 查看当前画布元素（用于规划与验证） |
| `clearCanvas` | — | 清空画布（一键生成新图前） |

### 系统提示词要点

- 角色：科研制图智能体，精通 AI 算法架构、大数据、医学机制、数学建模的图示惯例
- 规范：合理排版（对齐、间距）、配色建议、箭头连接语义
- 流程引导：先 `listElements` 了解现状 → 规划 → 逐元素 `createElement`/`updateElement`
- 坐标范围约束：0~1600 × 0~1000，越界自动钳制

### 生成流程

```
用户输入描述 → 客户端锁定画布（"AI 工作中"遮罩）→ POST /api/chat
携带：当前元素序列 + 消息历史 + 画布尺寸 + API Key
→ 服务端 agent 循环：模型调工具改服务端内存草稿
→ 每个工具执行后 SSE 流式推送进度事件（"正在添加 Encoder 模块…"）
→ 完成后流式返回最终画布状态 + AI 总结文字
→ 客户端替换画布，解锁，可继续对话修改
```

后续对话自动携带最新画布状态，支持"把损失函数那块改成蓝色"式精准修改。

## 6. 设置页（/settings）

- API Key 输入（存 localStorage，`sk-xxx`）
- 模型选择：`deepseek-chat`（默认）/ `deepseek-reasoner`
- Base URL 输入（默认 `https://api.deepseek.com`）
- "测试连接"按钮：调 `/api/test-key` 发最小请求验证 Key
- 未配置 Key 时，主页面顶部提示引导去设置

### 服务端路由

- `POST /api/chat`：agent 循环，SSE 流式响应
- `POST /api/test-key`：最小请求验证 Key（由服务端发起，避免 CORS）

## 7. 错误处理

- 未设置 API Key → 聊天区提示 + 引导去设置页；画布不锁定
- DeepSeek API 错误 → 聊天区显示错误信息；画布保持当前状态
- SSE 流中断 → 提示"生成中断，请重试"；服务端草稿丢弃，不影响当前画布
- 工具参数越界 → 服务端钳制到画布范围内
- 非法工具参数（如 type 不存在）→ 返回错误给模型重新调用

## 8. 测试策略（Vitest + Testing Library）

- **单元**：Zustand store（增删改、撤销重做）、几何工具（命中检测、对齐、吸附、缩放）、SVG/PNG 导出序列化
- **组件**：工具栏切换、属性面板联动、画布基本交互（渲染 + 事件模拟）
- **Agent**：mock AI SDK 工具循环，验证工具调用正确应用到草稿状态、流式事件顺序
- **启动器**：PowerShell 测试脚本（中文断言，.ps1 带 BOM）

## 10. 更新日志约定

沿用日程系统约定：功能改动追加到 `src/lib/changelog.ts` 当前版本；里程碑（本工具首个可用版本）开新版本，用日期时间命名。

## 11. 启动器

`tools/launcher/`：WinForms PowerShell GUI，一键启动/停止 `next dev`，显示日志输出，正常关闭不误报"意外退出"。.ps1 文件必须带 BOM（中文系统 PowerShell 5.1 兼容）。启动器开发遵循日程系统的既有模式。

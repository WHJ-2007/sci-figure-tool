# AI 三种模式（科研绘图 / 思维导图 / 图表制作）— 设计文档

日期：2026-08-06
状态：已批准

## 1. 概述

当前 AI 只有一套"科研制图"规范（logic 节点 + applyGraph 网格布局 + 科研调色板），用户要思维导图时 AI 会套用流程图风格，形式死板单一、内容空洞。本次迭代：

1. **三种模式**：科研绘图（现有规范）、思维导图（放射式）、图表制作（数据图表 + 通用图示），在聊天面板中可切换
2. **模式选择**：自动识别（AI 按用户消息判断）+ 手动覆盖（分段按钮）
3. **思维导图**：中心主题 + 曲线分支 + 线上关键词 + 子节点，放射式布局，内容必须有实质
4. **图表制作**：完整基础数据图表（坐标轴/刻度/数据标签/图例，AI 自动算刻度）+ 通用图示（时间轴/组织架构图/泳道图/维恩图）

## 2. 现状（改动基础）

- 系统提示单一：`src/lib/ai/prompt.ts` 的 `SYSTEM_PROMPT` 只教科研绘图规范（规则 1-14）
- 工具集：`createElement / applyGraph / connectElements / updateElement / deleteElement / listElements / clearCanvas / newCanvas`（`src/lib/ai/tools.ts`）
- agent：`runAgent` 单一 system prompt，`ChatPanel` 把 messages + canvas 发给 `/api/chat`
- 元素类型：`rect / ellipse / triangle / diamond / hexagon / arrow / polyline / text / logic`（`src/lib/canvas/types.ts`、`elements.ts`），无曲线、无扇形
- 布局引擎：`graphLayout.ts`（dagre，Task 44），已验证"语义与布局分离"思路
- 测试基线：21 文件 212 测试全绿（`npm test` = vitest + tsc --noEmit）

## 3. 功能 1：模式选择 UI 与请求流

### 3.1 UI（ChatPanel.tsx，输入框上方）

```
┌────────────────────────────┐
│ AI 助手              收起   │
│ [自动] [科研绘图] [思维导图] [图表制作]   ← 四枚分段小按钮，圆角胶囊
│ 描述你想画的图…              │
│ (一键生成)                   │
└────────────────────────────┘
```

- 四选一，默认「自动」。选中态蓝底白字，未选中白底灰字，风格与现有按钮一致（`.lift` 动效）
- 选中项按画布 id 持久化到 localStorage（key：`chartMode-<projectId>`），刷新/切换画布恢复

### 3.2 请求流

- 发送时把 `mode: "auto" | "sci" | "mindmap" | "chart"` 随 messages 一起 POST 到 `/api/chat`
- `agent.ts` 收到 mode：
  - `auto`：不传模式锁，AI 自行判断
  - 手动模式：system prompt 顶部加一行「本次任务模式：思维导图。只遵循思维导图规范节，忽略其他节」
- `AgentEvent` 不变，前端事件处理无需改动

## 4. 功能 2：系统提示三节结构与自动识别

### 4.1 prompt.ts 重组

保留现有画布规格 + 工具使用规范为公共节，新增三节风格规范：

- **科研绘图节**：现有全部规范（logic 节点、applyGraph 优先、科研调色板、审美规范），内容不变
- **思维导图节**：
  - 中心主题用 logic（大字号加粗标题）
  - 一级分支优先用 `applyMindMap` 声明式生成（曲线分支 + 线上关键词 + 子节点）
  - 关键词必须是实义语义名词（如"数据预处理""损失函数"），禁止空泛词（"分支1""子项2"）
  - 分支节点可带 body 要点展开概念；整图 3-5 个一级分支、每分支 1-3 层子分支
  - 每分支一色（6 色调色板循环），同分支子节点同色系
- **图表制作节**：
  - 数据图表优先用 `applyChart` 声明式生成（柱/折线/饼/散点，自动坐标轴刻度+图例+数据标签）
  - 通用图示（时间轴/组织架构图/泳道图/维恩图）用 applyGraph 或现有元素工具
  - 数据必须是用户给出的或常识合理的真实数值（示例：中国 GDP 2023 ≈ 126 万亿），禁止编造离谱数据
  - 数据量 3~12 项；图标题必填；刻度/图例文字字号 ≥12

### 4.2 自动识别

`auto` 模式时提示明确写判断规则：流程图/架构图/机制图 → 科研绘图；中心主题+放射分支/梳理思路 → 思维导图；数据可视化/柱状/折线/饼图/时间轴/组织架构 → 图表制作。AI 只使用对应节的规范。

## 5. 功能 3：新元素类型 curve 与 sector

两种均为 **AI 生成专用**（无工具栏绘制工具、无手动编辑手柄），进 `types.ts` 联合、`elements.ts`、`ElementShape` 渲染、exporter、undo/redo、listElements 描述。无旋转支持（rotation 忽略）。

### 5.1 curve（贝塞尔曲线分支线）

- 数据：`x/y`（起点）、`width/height`（终点相对偏移）、`curvature`（控制点弯曲度，0=直线，正值外凸，默认 0.5）
- 渲染：二次贝塞尔 `<path d="M x y Q cx cy x+w y+h">`，线宽可调
- 命中：点到二次贝塞尔的最小距离 < 8px（解析求解）
- 导出：SVG 直接 path；PNG canvas `quadraticCurveTo`
- 属性面板：起点/终点/线宽/颜色（坐标只读）

### 5.2 sector（饼图扇形）

- 数据：`x/y`（圆心）、`radius`、`startAngle/endAngle`（弧度，0 在 3 点钟方向顺时针）
- 渲染：SVG path `M 圆心 L 起边 A r r 0 largeArc 1 终边 Z`；PNG canvas `arc + lineTo`
- 命中：点在圆内且角度在区间内（含圆心）
- 属性面板：圆心/半径/角度只读

## 6. 功能 4：applyMindMap 工具与放射布局引擎

### 6.1 AI 调用（tools.ts 注册，draft.ts 新增 applyMindMap）

```
applyMindMap({
  topic: "深度学习",           // 中心主题（≤8 字）
  branches: [
    { keyword: "数据处理", body: "清洗\n增强", fill: "#eef4ff",
      children: [ { keyword: "归一化", body: "…" } ] }
  ]
})
```

### 6.2 引擎（`mindMapLayout.ts` 新文件，纯函数 + 单测）

1. **分支角度**：N 个一级分支均分 360°，从 12 点方向顺时针排；中心主题 logic 居中偏上（留出下方展开空间）
2. **曲线分支**：中心主题朝向该分支的锚点 → 关键词位置，画 curve，curvature 按方向外凸
3. **关键词位置**：一级分支半径 ~280px，子分支逐层 +180px，按角度展开（x = cx + r·cosθ，y = cy + r·sinθ）
4. **关键词呈现**：一级关键词 = 小 logic 节点（可带 body），子分支 = 线上关键词 text + curve 分叉
5. **防重叠**：同角度链子分支按层内均分角度（两个子分支各偏 ±12°），节点宽高参与坐标计算
6. **配色**：每分支一色（6 色调色板循环），同分支同色系
7. 超画布自动整体缩放（复用 Task 44 思路，位置缩放节点尺寸不变）

## 7. 功能 5：applyChart 工具与图表引擎

### 7.1 AI 调用（tools.ts 注册，draft.ts 新增 applyChart）

```
applyChart({ type: "bar"|"line"|"pie"|"scatter",
  title: "季度销售额", xLabel: "季度", yLabel: "销售额(万)",
  data: [ { label: "Q1", value: 120, series: "本店" } ] })
```

### 7.2 引擎（`chartLayout.ts` 新文件，纯函数 + 单测）

1. **绘图区**：固定区域（x 140~1540、y 120~860，标题/图例/刻度留白）
2. **刻度算法**：数据范围 → 取整刻度（max 123 → 上限 150、每格 50，5-6 格），刻度值 text 沿轴排布
3. **几何**：bar=rect（宽 90~260 柱区）；line=polyline + 数据点椭圆；pie=sector 数组；scatter=椭圆点
4. **结构**：坐标轴=两条 arrow；刻度线=短 rect/polyline；数据标签=text（值或百分比，字号 12~14）；图例=右上角小 rect 色块 + text（多系列时）
5. **配色**：6 色调色板，系列色依次取；刻度/标签文字 #4a5568
6. **多系列**：bar 并排分组、line 多条 polyline，图例区分
7. 超画布自动整体缩放

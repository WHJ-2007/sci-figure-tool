# 第四批需求设计：AI 智能升级 + 图表公式化 + 交互打磨

> 日期：2026-08-06。基于用户 9 条中文原话需求 + 3 项已确认决策（Tavily 联网搜索、饼图+柱状图公式化、AI 自动两阶段提问）。

## 用户需求清单（原文要点）

1. AI 不用必须写正文——要理解什么时候只写标题、什么时候只写正文、什么时候两者都写，真正理解而不是强制规定
2. AI 会使用线条功能进行简笔画绘制（如绘制图案）
3. 线条和别的任何元素右键加"删除"功能
4. AI 可上网搜索数据，只允许权威数据，不允许凭空编造和欺骗，反复检查整体正确性
5. 修复 bug：切换画布以后 AI 不进行任何操作
6. 删除"支持一键生成与对话修改"文案，一键生成按钮平铺到整个最下面
7. 打通逻辑：各种图标也是基于图案、线条、逻辑、箭头组合出来的——重新写好绘图脚本和 skill，统一操作；大胆加入更多图案类型或编辑功能
8. 图标要真正基于公式写数据和位置大小（如饼图：点击后由公式算出角度，拖动图形改大小数字跟着变；改数字图形跟着变；可取消与父级图表关联，取消后无公式无自动变化）
9. AI 对不确定的问题可以进一步提出问题，让用户回答，再生成

**已确认决策**：联网搜索 = Tavily API；公式化图表 = 饼图 + 柱状图；提问澄清 = 自动两阶段流。

## 子项目 A：AI 能力升级

### A1. 逻辑节点正文语义化（需求 1）

**现状**：prompt 多处强制 body 必填（COMMON 规则 11"必须写正文…禁止只有标题的空盒子"、SCI 规则 2"body 正文必填"、MINDMAP 规则 3"一级分支必须用 body 写要点"、applyGraph 描述"body 必填"），导致 AI 为每个框都塞正文。

**改动**：把"必填"改为"语义判断"——prompt 教会 AI 按节点语义自主决定正文策略：

- **概念/名词型**（"注意力""损失函数""编码器"）→ 只写标题，标题本身即完整语义，不写正文
- **过程/动作型**（"数据清洗""特征提取""降维"）→ 标题 + 2~4 行要点正文（每行 ≤12 字，交代做什么/包含什么）
- **输出/结论型**（"预测结果""分类输出"）→ 标题即可，需要时补一行正文
- **说明型**（需要解释的模块）→ 标题 + 正文
- 判断标准：**"标题是否已经完整表达该节点的语义"**——是则不需要正文，不是才写正文。同图风格统一（同一流程要么都有正文、要么都只有标题，不混搭）

**文件**：`src/lib/ai/prompt.ts`（COMMON 规则 11 重写、SCI 规则 2 改写）、`src/lib/ai/tools.ts`（applyGraph 的 body 描述从必填改可选+语义指导）、`src/lib/ai/draft.ts`（applyGraph body 校验从必填改可选）、`src/lib/ai/agent.test.ts`（适配 body 可选语义的测试）

### A2. 线条简笔画（需求 2）

**改动**：prompt 新增"简笔画与图示符号"规范节 + 工具描述增强，教会 AI 用线条（line = arrow + head:"none"）与基础形状组合画图示符号：

- 线条语义：纯线（无箭头），可用 midPoints 折点画任意折线轮廓；多条 line 拼出图案
- 简笔画配方（AI 组合手册，10 个常用图示符号）：灯泡（ellipse + rect 底座 + 2 line 光线）、齿轮（ellipse + 若干 line 齿）、云（3 ellipse 交叠 + rect 底）、旗帜（line 旗杆 + polygon 旗面）、放大镜（circle + line 柄）、书（2 rect + line 中缝）、星形（多条 line 折线）、漏斗（2 polygon）、天平（rect + line + 2 triangle）、心形（2 sector 半圆 + polygon 三角）
- 应用场景：机制图/流程图的装饰符号、图表旁的说明图示、强调标注
- 与 A1 共用"图标=基础元素组合"的认知（见子项目 D）

**文件**：`src/lib/ai/prompt.ts`（新增简笔画节）、`src/lib/ai/tools.ts`（createElement 描述补 midPoints 折线用法）、`src/lib/ai/agent.test.ts`

### A3. AI 提问澄清——自动两阶段（需求 9）

**流程**：
1. AI 判断需求模糊（如：图表没给数据且没说明主题、图种不明确、关键信息缺失）→ 调用新工具 `askUser(question)`，**不画任何东西**
2. agent 检测到 askUser 调用 → 立即停止循环 → 发 `question` 事件（含问题文本）
3. 前端收到 → 显示 AI 问题气泡（样式与普通消息一致，带"等待你的回答"副标）→ 输入框聚焦 + placeholder 变为"回答后继续生成…"
4. 用户发送回答 → 前端把「AI 问题 + 用户回答」追加进 messages，**复用现有 /api/chat 主流程**再次生成（上下文完整，AI 会继续执行；第一次调用未产生任何画布修改，baseline 机制天然正确）
5. 结果按现有 snapshot/complete/undo 基线机制落地

**关键实现**：
- `askUser` 工具：参数 `question: string`，服务端无副作用（不写 draft），活动日志显示"向用户提问：…"
- agent.ts：onStepFinish / 结果检查——`result.toolCalls` 中含 askUser → 发 `question` 事件 + 返回特殊状态（不再发 complete）
- 前端 ChatPanel：新增 `waitingAnswer` 状态；收到 question → setWaitingAnswer + 问题入 messages；send() 时若 waitingAnswer → 只追加消息继续正常流程（不需要特殊端点）
- 防呆：askUser 后 AI 若同时画了元素（不应发生）→ 按问题优先，元素丢弃（不发 snapshot）

**文件**：`src/lib/ai/agent.ts`（question 事件 + askUser 检测）、`src/lib/ai/tools.ts`（注册 askUser）、`src/lib/ai/draft.ts`（无需改，工具无副作用）、`src/components/editor/ChatPanel.tsx`（waitingAnswer 状态）、`src/lib/ai/agent.test.ts`、`src/components/editor/chat.test.tsx`

### A4. Tavily 联网搜索（需求 4）

**设置**：设置页「AI 服务」卡新增可选字段「Tavily API Key」（与 LLM Key 并列，localStorage 独立 key `tavilyApiKey`，不配置则 AI 无搜索能力）。`src/lib/settings.ts`、`src/app/settings/page.tsx`、`src/app/settings/settings-page.test.tsx`

**工具**：`searchWeb(query: string)`：
- 服务端调用 `POST https://api.tavily.com/search`（`{ api_key, query, search_depth: "basic", max_results: 5 }`）
- 返回精简结果：title、url、content（截断 ~200 字）
- apiKey 从请求体传入（与 LLM key 同路径），服务端执行，不透出给前端之外
- 失败处理：搜索失败返回错误信息给 AI（"搜索服务不可用"），AI 改用估算并明示

**prompt 规范**（写入 COMMON 或 CHART 节）：
- 用户给出数据 → 原样使用，禁止改动
- 用户没给数据但要具体数字（统计数据/年份/比例）→ 必须 searchWeb 查权威来源（政府机构、官方统计、学术期刊、国际组织）；**禁止凭空编造精确数字**
- 查不到权威数据 → 用常识范围合理估算，**收尾必须明示**"该数值为估算，未查到权威来源"
- 搜索后自查：引用的数字与搜索结果一致（不得改写），收尾可给出数据来源
- 每次生成最多搜索 2 次，引用时只取必要数字

**文件**：`src/lib/ai/tools.ts`（searchWeb 注册）、`src/lib/ai/agent.ts`（透传 tavilyApiKey）、`src/app/api/chat/route.ts`（接收 tavilyApiKey）、`src/lib/ai/prompt.ts`、`src/components/editor/ChatPanel.tsx`（发送 tavilyApiKey）、`src/lib/settings.ts`、`src/app/settings/page.tsx`、新增 `src/lib/ai/search.ts`（Tavily 调用封装）+ `src/lib/ai/search.test.ts`（mock fetch）

### A5. 画布切换 AI 失活 bug（需求 5）

**根因**（已定位）：
1. `store.setCurrentProject` 只切换 doc/history/selection/editingText，**残留 aiLockedIds / aiBaselineIds / isGenerating**（旧画布状态污染新画布；若切换时生成中，旧快照还会 merge 进新画布）
2. ChatPanel 的 messages **跨画布保留**，AI 上下文还停留在旧画布的元素上，listElements 却返回新画布内容 → AI 困惑/不操作

**修复**：
- `store.setCurrentProject`（及 deleteProject 切画布路径）重置 `aiLockedIds: []`、`aiBaselineIds: []`
- ChatPanel 监听 `currentProjectId` 变化 → 清空 messages、error、confirmReq、waitingAnswer（画布即会话边界，新画布新对话）
- 生成中切换画布防御：ChatPanel 在 fetch 前记录 `requestProjectId`，每个 snapshot/complete/confirm 事件到达时校验 `requestProjectId === 当前 currentProjectId`，不一致则**丢弃该事件**（不 apply、不入锁），只发 error 提示"画布已切换，本次生成已丢弃"（或静默丢弃）
- `setGenerating(false)` 在 finally 无条件执行（现有逻辑已如此，保留）

**文件**：`src/lib/canvas/store.ts`、`src/components/editor/ChatPanel.tsx`、`src/lib/canvas/store.test.ts`、`src/components/editor/chat.test.tsx`

## 子项目 C：图表公式化（饼图 + 柱状图，需求 8）

### C1. 数据绑定模型

**设计**：元素上挂 `bind` 字段：

```ts
// types.ts（CanvasElement 扩展）
bind?: { chartId: string; role: "slice" | "bar" | "pie-label" | "bar-label" | "pie-legend" | "axis" | "title" | "x-label" | "y-label" | "grid"; index: number };
```

- `role + index` 唯一标识数据项（slice-i / bar-i 对应 `spec.data[i]`）；非数据项（轴/标题/图例）无 index 或固定 role
- `chartLayout` 为生成的每个元素打上 bind（chartId 由 applyChart / applyChartEdit 参数注入后统一附上——`layoutChart(spec, chartId?)`）
- `charts[chartId]` 声明不变（ChartSpec），bind 提供元素 ↔ 数据反向映射
- 兼容：旧数据无 bind → 无联动（数据表编辑仍全量重排，行为与现状一致）

### C2. 联动机制

**数据 → 图形**（改数字图形跟着变）：
- 现有 ChartDialog 编辑 → `applyChartEdit(chartId, spec, layoutChart(spec, chartId), replaceIds)` 全量重排（已实现，增强：重排时保留 bind）
- 新增 `recomputeChart(chartId)`：按当前 `charts[chartId]` 重算该图表全部绑定元素，替换画布中 bind.chartId === chartId 的元素（等价的 applyChartEdit 封装，供拖动路径调用）

**图形 → 数据**（拖扇形/柱顶，数字跟着变）：

*饼图扇形角度拖动*：
- 选中 sector 元素（bind.role === "slice"）→ 拖动时进入"图表联动"模式：**圆周方向拖动**改变该扇形的终止角度（sweep 增减，拖动起点记录当前指针极角）
- 新 value = total × newSweep / 2π（total 不含被拖项，其余项保持原值，总和自动守恒）；夹紧到 [0.5, total × 0.95]（防全占/归零）
- 联动结束后 recomputeChart 重排整图（扇形/百分比标签/图例数字同步更新），**一次拖动 = 一步撤销**

*柱状图柱顶拖动*：
- 选中柱 rect（bind.role === "bar"）→ 拖动垂直方向改变柱高 → new value = 指针 y 换算的数值（按 niceScale max 钳制 ≥0）→ recomputeChart 重排（柱形、数值标签、y 刻度联动）
- 拖动手感：拖动中显示虚线参考线（y 方向）

**实现位置**：`usePointerInteraction` 的 move 模式前置判断——命中元素有 bind 且角色可拖 → `chart-edit` 模式（pointermove 换算极角/数值，pointerup 后 recomputeChart 入历史）；`SelectionOverlay` 无需新手柄（直接拖元素本体：扇形本体=扇形区域拖改角度；柱本体=柱面拖改高度）

### C3. 解除关联

- 属性面板数据卡（选中图表元素时）新增「解除图表关联」按钮
- 点击 → 该 chartId 全部元素移除 bind（保留为普通元素，可任意拖动/缩放/改色/删除）→ `charts` 中删除该 chartId → 属性面板数据卡消失
- 解除后无公式无自动变化（数据表对话框不再回填该图）
- 一步撤销恢复关联？——**不做**（解除是单向操作，撤销恢复关联复杂；用户在需求中未要求撤销恢复）

**文件**：`src/lib/canvas/chartLayout.ts`（bind 打标 + layoutChart 签名）、`src/lib/canvas/types.ts`、`src/lib/ai/draft.ts`（applyChart 后给元素附 bind）、`src/lib/canvas/store.ts`（recomputeChart、detachChart）、`src/components/editor/ChartDialog.tsx`（applyChartEdit 调用适配）、`src/components/editor/usePointerInteraction.ts`（chart-edit 模式）、`src/components/editor/PropertyPanel.tsx`（解除关联按钮）、`src/components/editor/SelectionOverlay.tsx`（chart 联动命中层/参考线，如需要）、`src/components/editor/panels.test.tsx`、`src/components/editor/Canvas-interaction.test.tsx`、`src/lib/canvas/chartLayout.test.ts`、`src/lib/canvas/store.test.ts`、`src/lib/ai/agent.test.ts`

### C4. 数据表对话框适配

ChartDialog 打开时从 `charts[chartId]` 读取 spec（现状）；**兼容 bind 模型**——对话框保存 → applyChartEdit 带新 bind 重排。无额外改动。

## 子项目 D：AI 绘图逻辑打通 + skill 重写（需求 7 核心）

**认知注入**：prompt 新增「绘图世界观」节——**任何图示 = 基础元素组合**：

> 画布上的每个东西都由基础元素拼成：图案（矩形/圆角/椭圆/三角/菱形/六边形/五角星/十字/圆环/半圆）、线条（无头箭头折线，可加折点）、逻辑节点（语义模块）、箭头（含 head 样式）、文字。图标、符号、示意图都是这些元素的组合。画图 = 决定"要什么形状 → 用什么元素 → 位置多大 → 什么颜色"，先规划组合再逐个创建。

**组合手册**（A2 简笔画配方 + 常用科研图示配方）：
- 流程/架构：logic 节点 + arrow（applyGraph 优先）
- 数据图：applyChart
- 思维导图：applyMindMap
- 图示符号：基础元素组合（灯泡/齿轮/云/旗帜/放大镜/书/星形/漏斗/天平/心形等 10 个配方）

**统一操作说明书重写**（COMMON 规则整理为一张决策表）：
- 需求是流程图/架构 → applyGraph
- 需求是导图 → applyMindMap
- 需求是数据图 → applyChart
- 需求是单图/装饰/符号 → createElement 组合
- 需要连线 → connectElements；纯线/装饰线 → createElement arrow head:"none" + midPoints
- 改 → updateElement；删 → deleteElement；看现状 → listElements

**自查规则升级**（需求 4 的"反复检查整体正确性"）：画完 2 轮自查——① 结构（重叠/空盒/越界/间距，现有）② **数据与事实**（引用的数字与搜索来源一致、无编造、百分比合计合理、图例与数据一致）

**文件**：`src/lib/ai/prompt.ts`（绘图世界观节 + 组合手册 + 决策表 + 自查升级）、`src/lib/ai/agent.test.ts`、`src/lib/ai/prompt.test.ts`

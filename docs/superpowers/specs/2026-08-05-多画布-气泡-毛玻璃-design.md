# 持久化多画布 + AI 行为调整 + 生成气泡 + 全局毛玻璃 — 设计文档

日期：2026-08-05
状态：已批准

## 1. 概述

四项改动：

1. **持久化多画布**：画布列表存 localStorage（刷新保留），支持新建/切换/重命名/删除；撤销栈按画布隔离
2. **AI 行为调整**：默认在现有画布上修改/叠加，改不了才新建画布（新 `newCanvas` 工具）；clearCanvas 仅限用户明确要求
3. **左下角生成气泡**：AI 生成中单条步骤循环显示，弹出/收缩动画，点击展开聊天面板
4. **全局毛玻璃**：浅色渐变背景 + 工具栏/面板/引导条/气泡半透明 backdrop-blur

## 2. 多画布数据模型与 store 改造

### 2.1 新文件 `src/lib/canvas/projects.ts`

```ts
CanvasProject = { id: string; name: string; doc: CanvasDocument; history: HistoryState }
```

- `loadProjects(): CanvasProject[] | null` — 读 localStorage `sci-figure.projects.v1`（存 `[{id,name,doc}]`，剥 history）；无 key / JSON 损坏 / 数组空 → null
- `saveProjects(projects)` — 写 `[{id,name,doc}]`
- `makeProject(name?): CanvasProject` — id 用时间戳；history 为空
- `defaultProjectName(existing)` — "画布 N"（N 取现有最大序号 + 1）

### 2.2 store 兼容改造

- 保留顶层 `doc`/`history` 字段语义（= 当前项目），新增 `projects[]` + `currentProjectId`
- 所有涉及 doc/history 的 setter（addElement/addElements/updateElement/updateElementFast 不涉及 history/deleteElements/moveElements 不涉及/commitHistory/setDoc/applyAISnapshot/applyAIResult/undo/redo）通过统一 helper `syncProject(s, doc, history)` 写回当前项目（返回 `{ doc, history, projects }`）
- 新方法：
  - `createProject(): string` — 新建"画布 N"并切换（doc/history 替换为空态，selection/editingText 清空，view 重置）
  - `renameProject(id, name)`
  - `deleteProject(id)` — 最后一张不可删；删除当前 → 切到相邻项目
  - `setCurrentProject(id)` — 替换 doc/history 为该项目，清空 selection/editingText
- 初始化：`typeof window !== "undefined"` 守卫读 localStorage；无数据 → 默认"画布 1"
- 持久化时机：store 创建后 `subscribe` 监听全部变化 → 300ms 防抖 `saveProjects`（剥 history）

### 2.3 测试隔离

所有 reset store 的测试 beforeEach 增加 `localStorage.clear()`（防止项目数据跨测试文件残留污染）。

## 3. AI 行为 + newCanvas 工具

- **prompt.ts**：新增规范条目——默认在现有画布上修改/叠加，尽量复用已有元素；仅当现有内容确实无法承载用户需求时才调用 newCanvas；clearCanvas 仅在用户明确要求清空/重画时使用
- **draft.ts**：`newCanvas()` — 清空草稿、activity 记录"新建画布"、触发 onChange、置 `newCanvasFlag`；`takeNewCanvasFlag()` 供 agent 取走
- **agent.ts**：AgentEvent 新增 `{ type: "new-canvas"; name: string }`；onChange 钩子检测 flag 时先发 new-canvas（name 由客户端侧序号生成则事件不带 name？——事件携带 name: string，服务端从 draft 读取，客户端可忽略/使用）
  - 简化：事件 `{ type: "new-canvas" }` 无字段；name 由客户端 createProject 的默认命名逻辑生成
- **tools.ts**：新增 `newCanvas` 工具（description：创建新画布，仅当现有画布无法承载用户需求时使用）
- **ChatPanel**：收到 `new-canvas` → `createProject()`（切换后 baseline 语义自然变为新画布空态）→ 后续 snapshot/complete 落到新画布
  - 注意：new-canvas 后 baseline 重置为新画布初始空态，complete 的 applyAIResult(finalDoc, baseline=空) 一步撤销回到空画布

## 4. 左下角生成气泡（`GenerationToast.tsx` 新组件）

- 订阅 `isGenerating` 与 activity 最新一条；无 activity 时显示"AI 正在生成…"
- 动画：CSS transition——弹出（opacity 0→1 + translateY(8px)→0），收缩（反向 + 200ms 延迟卸载）
- 位置 fixed 左下角（bottom-4 left-4），z 高于面板
- 点击气泡 → 展开聊天面板：ChatPanel 的 `open` 状态提升到 `page.tsx`（useState + props 下发）
- 面板内完整步骤日志保留

## 5. 全局毛玻璃

- `globals.css`：body 背景浅色渐变（indigo-50 → white → purple-50 等），html/body 高度不变
- 工具栏/属性面板/聊天面板/引导条/气泡：`bg-white/60 backdrop-blur-md`、边框 `border-white/40`（替换现有 `bg-white border-gray-200`）
- 画布区域无背景（透出渐变）
- 文字颜色不变（浅底半透明上深色文字可读）

## 6. 测试

- **store**：多画布 CRUD、切换、history 隔离（A 画布操作后切 B 再切回 A，undo 栈独立）、localStorage 读写（含损坏 JSON 回退默认）

# 科研制图工具（sci-figure-tool）

AI 辅助的科研示意图编辑器：一键生成 AI 算法架构图、大数据 / 医学机制图、数学建模图形、数据图表与思维导图，也支持完全手动绘制。

## ✨ 功能特性

- **AI 一键绘图**：自然语言描述即可生成科研图 / 思维导图 / 数据图表（柱状图、折线图、饼图、散点图），AI 自动判断图种与布局
- **多图种组合**：同一张画布可自由组合科研绘图、思维导图、图表小节与图标简笔画，风格统一
- **图表公式化**：生成的数据图表是整体「图对象」——可整体移动、拖扇形 / 柱顶直接改数值（图形与数据联动）、编辑数据整图重排、解除关联
- **画笔工具**：自由手绘笔迹，基于 $1 手写识别——手写箭头自动替换为规整箭头（同方向 / 大小 / 粗细），一步撤销复原手写
- **AI 提问按钮化**：所有提问渲染为可点击选项，点选即继续生成；支持联网搜索（Tavily）补充权威数据
- **跨画布引用**：AI 可读取其他画布内容参考 / 模仿（对话中显示「引用了…画布」标识），但绝不切换画布
- **多画布多对话**：每张画布独立保存、视口位置记忆（缩放 / 平移刷新后恢复）、每画布多个对话标签页
- **精细编辑**：PPT 式对齐参考线（移动 / 缩放 / 绘制全程可见）、吸附、组合对象、镜像、饱和度控制、图层排序、画布样式
- **高质量导出**：SVG（矢量，论文用）/ PNG（4x 超采样 6400×4000，放大无锯齿）
- **本地保存**：支持选择本地目录瞬时保存（canvas-data.json），也持久化在浏览器本地

## 🚀 使用

1. 双击 `启动器.bat`（或 `npm run dev`，端口 3001）
2. 打开 http://localhost:3001
3. 齿轮图标 → 设置 → 填写 DeepSeek API Key（可自定义模型与 Base URL）→ 测试连接
4. 回到画布：手动画图，或在 AI 助手输入描述一键生成

## 🎨 常用操作

- 工具栏选择形状后拖拽绘制；点击选中 / 拖动元素 / Shift 多选 / 缩放手柄
- 空白画布左键拖动 = 平移画布；右键拖动 = 多选框选；空白点击清空选择
- 双击文字编辑；Delete 删除；Ctrl+Z / Ctrl+Y 撤销重做；Ctrl+D 复制
- WASD 平移画布（按下即动，按住连续移动）
- 多选后旋转手柄整组旋转（绕几何中心）
- 导出：SVG（矢量）/ PNG（4x 超高清）
- 左侧悬浮坞：工具、撤销 / 重做、画笔、图表（手动生成数据图表）
- AI 生成中画布可继续操作：AI 正在编辑的元素带蓝色虚线框（锁定），生成完自动解锁

## 🤖 AI 助手

- **三种模式**：科研绘图（流程图 / 架构图 / 机制图）、思维导图（中心主题 + 放射分支）、图表制作（数据图表 / 时间轴 / 组织架构等）
- **模式选择**：默认「自动」——AI 按描述自动判断图种；也可手动点选具体模式（可多选）锁定规范，AI 会在所选图种范围内自由组合
- **画笔理解**：AI 理解画笔语义（任何复杂轮廓 = 连续曲线 + 组合），能用手绘笔迹画符号 / 复杂结构图标
- **数值单位**：图表数据有明显单位时 AI 自动标注；饼图默认只显示占比，可选项显示「数值单位 (百分比)」
- 破坏性操作（清空 / 删除）会先弹确认框

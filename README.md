# 科研制图工具

AI 辅助的科研示意图编辑器：AI 算法架构图、大数据/医学机制图、数学建模图形。

## 使用

1. 双击 `启动器.bat`（或 `npm run dev`，端口 3001）
2. 打开 http://localhost:3001
3. 齿轮图标 → 设置页 → 填写 DeepSeek API Key → 测试连接
4. 回到画布：手动画图，或在右下角 AI 助手输入描述一键生成

## 常用操作

- 工具栏选择形状后拖拽绘制；点击选中/拖动元素/Shift 多选/缩放手柄
- 空白画布左键拖动 = 平移画布；右键拖动 = 多选框选；空白点击清空选择
- 双击文字编辑；Delete 删除；Ctrl+Z 撤销；Ctrl+D 复制
- WASD 平移画布（按下即动，按住连续移动，松开即停）
- 多选后可对齐/分布
- 导出：SVG（矢量，论文用）/ PNG（位图）
- 左侧悬浮坞：工具（图案/逻辑分区气泡）、撤销/重做、图表（手动生成数据图表）
- AI 生成中画布可继续操作：AI 正在编辑的元素带蓝色虚线框（锁定），生成完自动解锁
- AI 的新建画布/清空/删除操作会先弹确认框，可逐条确认或取消

## AI 助手

- 三种模式：科研绘图（流程图/架构图/机制图）、思维导图（中心主题 + 放射分支）、图表制作（数据图表/时间轴/组织架构等通用图示）
- 模式选择：默认「自动」——AI 按你的描述自动判断图种；也可手动点选具体模式（可多选）锁定规范，AI 会在所选图种范围内自由组合（如科研图中内嵌图表小节）；选择随画布保存，刷新后恢复
- 图表可手动编辑：左侧坞「图表」按钮生成数据图表；选中图表元素在属性面板「编辑图表数据」改数据后整图重排
- 破坏性操作（新建画布/清空/删除）会先弹确认框
